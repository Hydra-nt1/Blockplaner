# Blockplaner

Minecraft-Bauprojekte im Browser in 3D planen: Blöcke aus Java Edition 26.3 setzen, Gebäude Ebene für Ebene nachbauen, Materiallisten in Stapeln ablesen und Fotos in Blöcke oder 3D-Blaupausen umwandeln.

**App öffnen:** https://hydra-nt1.github.io/blockplaner/

## Für Freunde

- Link öffnen, fertig. Es ist kein Konto nötig.
- **Als App installieren:** Am Handy im Browser-Menü „Zum Startbildschirm hinzufügen“ wählen (iPhone: Teilen → „Zum Home-Bildschirm“), am PC in Chrome/Edge „App installieren“. Danach funktioniert die App auch offline.
- **Original-Texturen:** Unter „Blöcke → Spieldatei laden“ die eigene `26.3.jar` aus dem Minecraft-Ordner wählen (Windows: `%APPDATA%\.minecraft\versions\26.3\`). Die Datei wird nur im eigenen Browser gelesen.
- **Bauten teilen:** Unter „Projekte“ gibt es „Bau-Link teilen“ (öffnet den Bau direkt beim Empfänger) und „Als Datei speichern“ (`.blockplaner`-Datei, z. B. für Discord).
- **Sicherung:** „Projekte → Alle Projekte sichern“ speichert alle Bauten in einer Datei.

Projekte werden im jeweiligen Browser gespeichert und nicht auf einen Server hochgeladen.
